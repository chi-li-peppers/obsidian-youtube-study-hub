# Security policy

## How YouTube Study Hub handles your data

- Network requests go only to `youtube.com` when you explicitly run an import command.
- No API keys, credentials, analytics, or third-party servers are used.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/chi-li-peppers/obsidian-youtube-study-hub/security/advisories/new) instead of opening a public issue.
