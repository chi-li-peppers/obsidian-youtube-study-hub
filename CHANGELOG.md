# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-24

### Added

- Single YouTube video import with structured chapter extraction, description timestamp fallback, clickable timestamp headings and YAML frontmatter
- YouTube playlist to course converter generating numbered lesson notes and `_Course Index.md` with an auto-updating progress bar and checklist
- Command to fetch chapters later for lightweight lesson notes
- Duplicate note protection modal, filename sanitization and full settings tab
- Desktop and mobile support via Obsidian's `requestUrl`
